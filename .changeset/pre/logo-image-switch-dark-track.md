`FiestaLogo` is now one image named "FiestaBoard" (`role="img"`, optional `label`), with the lockup text hidden from assistive tech, and exports `FIESTA_LOGO_WORDMARK_SELECTOR` (`.logo-fiesta-text`) — the one selector a consumer's axe run should exempt under the WCAG 1.4.3 logotype exception. In dark, an off `Switch` track uses `--input` so it reads at 3.58:1 on a card instead of vanishing (1.10:1).
